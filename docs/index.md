# PortBackRank Documentation

Welcome to the official documentation for **PortBackRank**, a Python-based tool focused on simulating and backtesting investment strategies based on asset ranking.

This documentation aims to cover the entire scope of the project, both for users who wish to run simulations and for academic researchers working on related experiments.

## Documentation Index

- **[Getting Started](getting_started.md)**
  Learn how to install, configure `config.json`, and run your first backtesting simulation.

- **[System Architecture](architecture.md)**
  Understand the design, execution flow, and communication between system modules. Includes the class diagram.

- **[Modules Reference](modules_reference.md)**
  In-depth technical documentation of the main software components: `Data`, `Ranker`, `Runner`, and `Backtesting`.

- **[Experiments and Tracking](experiments_and_tracking.md)**
  A guide focused on academic requirements, detailing how to set up simulation grids, handle price types, and analyze the results extracted in the `tracking/` folder.
